# Minecraft Translate Neo

A Minecraft Forge mod that provides real-time translation of chat messages between different languages, making multiplayer gaming more accessible across language barriers.

## Features

### 🌍 Real-Time Chat Translation
- **Incoming Translation**: Automatically translate messages from other players into your preferred language
- **Outgoing Translation**: Translate your messages into a target language before sending them
- Support for multiple languages including English, Spanish, French, German, Dutch, and many more

### ⚙️ Easy Configuration
- **In-Game Settings**: Access translation settings through a clean, intuitive GUI
- **Language Selection**: Choose different languages for incoming and outgoing translations
- **Toggle Controls**: Enable/disable translation features independently
- **Persistent Settings**: Your preferences are saved automatically

### 🎮 Seamless Integration
- Works with existing Minecraft chat system
- No server-side installation required
- Compatible with other chat-related mods
- Lightweight and performance-friendly

## Installation

1. Download and install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the Minecraft Translate Neo mod jar file
3. Place the jar file in your Minecraft `mods` folder
4. Launch Minecraft with the Forge profile

## Usage

### Accessing Settings
- Open the translation settings through the mod's interface
- Configure your preferred languages for incoming and outgoing translations
- Enable or disable translation features as needed

### Language Support
The mod supports translation between numerous languages including:
- English
- Spanish (Español)
- French (Français)
- German (Deutsch)
- Dutch (Nederlands)
- Italian (Italiano)
- Portuguese (Português)
- Japanese (日本語)
- Chinese (中文)
- And many more...

### How It Works
1. **Incoming Messages**: Other players' messages are automatically detected and translated to your chosen language
2. **Outgoing Messages**: Your messages are translated to the target language before being sent to other players
3. **Real-Time**: All translations happen instantly without interrupting gameplay

## Requirements

- Minecraft 1.21.X
- Minecraft Forge
- Java 21 or higher
